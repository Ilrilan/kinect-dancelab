# DanceLab

Личная танцевальная игра-оболочка на ПК с проектором и сенсором глубины Kinect v2. Цель не развлечение, а отработка хореографии и пластики тела с измеримой обратной связью.

Разработка spec-driven: владелец пишет контракты и сценарии, код пишут агенты по спеке. Вход в спеку: `specs/system.md`. Правила работы: `CLAUDE.md`.

## Что есть сейчас

- Спеки в `specs/`: система, ядро (поза, модель данных, скоринг), слой захвата, Studio, Player, железо, датасеты, журнал решений, реестр непроверенных оценок.
- Слой захвата на C# (`src/DanceLab.Capture*`): интерфейс `IPoseSource`, реализации для Kinect SDK 2.0 и Nuitrack, запись замеров. Консоль `tools/sensor_probe`.
- Скрипты на Node TS (`tools/`): сводка по записям, анализ сцены по глубине, превью, загрузка видео AIST, сводка FineDance.
- Импортёр датасетов на Python (`tools/aist_import`): формат AIST++, SMPL, FineDance.
- Документы-снимки в `docs/`: форматы и состав датасетов, замеры на сенсоре, разбор обрывов Kinect.

Датасеты, записи сенсора и стороннее ПО в репозиторий не попадают (`data/` в `.gitignore`).

## Сборка и проверки

```
dotnet build DanceLab.sln
dotnet test tests/DanceLab.Capture.Tests/DanceLab.Capture.Tests.csproj
npm install
npm run check
```

Запись замеров с сенсора: `docs/sensor-probe-howto.md`.
