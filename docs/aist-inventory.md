## Видео 10M

Для 411 последовательностей по 9 ракурсов: 3699 файлов. На диске 3698. Не хватает одного: gMH_sBM_c09_d22_mMH2_ch01.mp4. Его нет в списке ссылок AIST (ни в raw, ни в refined), прямой запрос по ссылке возвращает 404. Остальные 8 ракурсов этой последовательности есть. Проверка структуры (ftyp, moov, mdat, конец по размеру) пройдена для всех 3698 файлов: битых нет. Размер файла от 8,3 до 62,6 МБ, медиана 11,9 МБ, всего 53 ГБ.

Следствие: у последовательности gMH_sBM_cAll_d22_mMH2_ch01 восемь ракурсов вместо девяти. Для наших задач (показ эталонного танцора) хватает любого одного ракурса.
