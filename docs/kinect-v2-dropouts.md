# Kinect v2: обрывы потока на Windows 11 (разобрано 2026-11-16)

Симптом. Kinect v2 на двух ноутбуках с Windows 11 (AMD и Intel) работает несколько секунд, затем каждые 3-14 секунд перезапускается: лампочка на сенсоре гаснет на 1-2 секунды, устройства Xbox NUI Sensor и USB Composite Device исчезают из системы, внутренние хабы сенсора остаются, лампочка родного блока питания горит ровно. В журнале событий отключений USB нет. Kinect Configuration Verifier при этом даёт карты глубины.

Причина. Эффект обработки звука Voice Clarity (VocaEffectPack, устройство AudioProcessingObject) на микрофоне Xbox NUI Sensor. Драйвер Kinect воспринимает сбой звукового тракта как неисправность и перезапускает сенсор (описание на Reddit, найдено владельцем). На нашей системе эффект подтверждён в реестре: у входа Xbox NUI Sensor привязан VocaEffectPack, в системе установлено устройство Voice Clarity.

Решение, подтверждённое владельцем: Параметры, Система, Звук, Ввод, Набор микрофонов (Xbox NUI Sensor), Улучшение звука Выкл. После этого отключения пропали.

Что оказалось не причиной: контроллер USB (AMD и Intel одинаково), блок питания, USB selective suspend, экономия энергии USB, видеокарта.

Практическое правило для установки на новом компьютере: после установки драйвера Kinect сразу отключить улучшение звука на микрофоне Xbox NUI Sensor, иначе первые запуски будут выглядеть как неисправность сенсора. Обновления Windows могут включить эффект снова.

Побочные изменения, сделанные при поиске причины (можно оставить, на работу не влияют): отключен USB selective suspend в схемах питания Silent и Сбалансированная, отключена экономия энергии на USB-устройствах.
