Коммиты делать самому, без вопроса, смысловыми порциями по темам (скиллы, правила, спеки, документы, инструменты), с атрибуцией из системного напоминания.

Push тоже делать самому: после каждого законченного логического этапа, либо после 2-3 часов активной работы, если этапа не было. Ждать напоминания владельца не нужно.

**Why:** владелец 2026-11-09: «тебе не нужно мое разрешение на коммиты, делай их смысловыми». 2026-11-18 расширил: «если мы что-то меняем в течение дня и я не напоминал тебе про коммит-пуш, после каждого законченного этапа логического или хотя бы 2-3 часов работы активной ты должен делать коммит-пуш, чтобы не потерять локальную работу». Старое ограничение «push только по слову» снято. Согласуется с [[general-working-rules]].

**How to apply:** закончил этап или прошло 2-3 часа активной работы с незапушенными коммитами: коммит, затем `git push` (ветка main привязана к origin, push может ждать окно авторизации GitHub до 2 минут, запускать в фоне). Смену ветки, force-push и переписывание истории по-прежнему не делать без отдельного слова. Входные артефакты (`source_artifacts/`) и данные (`data/`) в репозиторий не попадают.
