Определения ролей (`.zcode/agents/*.md`: `model`, `thoughtLevel`, `tools`) читаются один раз при старте сессии ZCode. Внутри работающей сессии они не обновляются.

Проверено 2026-11-23, при смене главной модели на GLM-5.4:

- Правка `model` в файле роли не подхватилась: после правки explorer на GLM-5.4-Flash тест-спавн отчитался моделью GLM-5.3-Flash.
- Новый файл роли сессия не видит: спавн с типом probe54 вернул «Agent type not found».
- Списка моделей тарифа не нашлось ни в конфиге (`~/.zcode/v2/setting.json`, `provider_config.json`), ни в логах за два дня: поиск по ключам availableModels, modelList, modelOptions, models и по id вида GLM-5.4-Flash пустой. Существование id модели проверяется только спавном.

## Как применять

Смена модели роли: правка фронтматтера всех ролей, коммит, новая сессия, тест-спавн. Тест-спавн просит агента процитировать строку «You are powered by the model named …» из его промпта. Имя в файле не доказывает, на какой модели отработал спавн; доказывает цитата из промпта. Неверный id всплывает на первом же спавне новой сессии.

Тот же класс ловушки, что [[dev-environment-pitfalls]]: проверка прошла не на том объекте. Правила запуска сабагентов: [[general-working-rules]].
