# Реестр непроверенных оценок

> Status: draft
> Назначение: числа, которые пока ничем не подтверждены, но первая оценка лучше, чем ничего.

Правила реестра.

- Здесь только числа без подтверждения. Подтверждённое значение переезжает в контракт соответствующего спека, строка отсюда удаляется.
- Источник указывает, откуда число взялось. Если оценка моя (агента), это написано явно: владелец её не подтверждал.
- Для каждой оценки указано, чем её можно проверить. Без способа проверки оценка не попадает в реестр.
- Нельзя ссылаться на эти числа в сценариях и контрактах как на требования. Они ориентир для реализации и для порядка измерений.

## Как пополнять

1. Любое число из диалога, не подтверждённое владельцем или измерением, заносится сюда с источником.
2. Подтверждённое измерением число переезжает в контракт, строка удаляется, в сообщении коммита указан ID.
3. Число, от которого владелец отказался, удаляется с пометкой в коммите.
