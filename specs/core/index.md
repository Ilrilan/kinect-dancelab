# Core: общий формат и скоринг

> Status: draft
> Parent: [../system.md](../system.md)

Core это общая библиотека формата, на которой разговаривают Studio и Player: каноническая поза, модель данных (бандл трека, запись сессии, профиль, производный кеш, агрегаты) и скоринг. От Core зависит всё остальное, поэтому формат версионируется, а определение позы замораживается вместе с версией.

Источник переносимого содержимого: spec/10-canonical-pose.md, spec/20-data-model.md, spec/50-scoring.md.
