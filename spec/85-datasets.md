# 85. Датасеты

## AIST++ — основной источник

Выбран основным **из-за видео**: это единственный танцевальный датасет с
кадрами изображений, у остальных только mocap. А в интерфейсе эталонное видео —
половина компоновки.

- 1408 последовательностей, 30 исполнителей, 10 жанров, 5,2 часа
- 60 fps, формат SMPL (вращения — то, что нужно)
- **9 синхронных ракурсов с известными параметрами камер**
- Реконструкция из многокамерного видео → есть ошибка восстановления, кистей нет

**Ключевая особенность**: AIST — обучающая база, где несколько танцоров
исполняют **одну и ту же хореографию** под разную музыку с разным BPM. Отсюда
берётся межисполнительский разброс, то есть коридор допуска. Без него у метрики
нет шкалы.

### Жанры (коды в именах файлов)

Break (BR), Pop (PO), Lock (LO), Waack (WA) — Old School;
Middle Hip-Hop (MH), LA-style Hip-Hop (LH), House (HO), Krump (KR),
Street Jazz (JS), Ballet Jazz (JB) — New School.

Категории: Basic (sBM), Advanced (sFM), Group (sGR). Групповые в AIST++ не
аннотированы.

Имя файла кодирует жанр, ситуацию, танцора, камеру, музыку и хореографию —
выборка строится по именам, без парсинга метаданных.

### Распределение — важно для плана библиотеки

Движения распределены равномерно по жанрам: ~140 последовательностей на жанр,
из них **85% базовых и 15% продвинутых** (длинные хореографии, свободно
придуманные танцорами).

То есть **связок для разучивания целиком около 200**, а не 1408. Остальные
1200 — короткие базовые элементы по 7–13 секунд.

Это не минус: базовые образуют **библиотеку упражнений**, словарь жанра. Для
отработки пластики словарь полезнее связок — элемент можно повторять по кругу.

Естественно получаются два режима: разучивание элементов и прогон хореографии.

### Объёмы

| Что | Размер |
|---|---|
| Вся AIST Dance DB | ~515 ГБ (13 940 видео, 60 музыкальных пьес) |
| Все видео 10 Мбит/с | 514 ГБ / 118,1 ч |
| **Все видео 2 Мбит/с** | **82 ГБ** / те же 118,1 ч |
| Музыка wav | 658 МБ |
| Музыка mp3 | 95 МБ |
| keypoints3d | 876 МБ |
| keypoints2d | 1,3 ГБ |

**Брать 2 Мбит/с, не 10.** Разница в битрейте покупает качество картинки,
которое для работы с позами не нужно, а выкачивать с академического сервера
полтерабайта ради неиспользуемого битрейта невежливо.

**keypoints не нужны вообще** — нужны вращения (motions), а не точки.

Минимум под работу: motions + камеры + музыка + выбранные видео ≈ менее 2 ГБ.
Клип 13 с при 2 Мбит/с ≈ 3 МБ.

Качать по отдельным URL или через фильтрованный поиск. **Не запускать массовый
загрузчик** из их инструкции — притащит 515 ГБ.

### Зачем все 9 ракурсов

1. Выбор ракурса под постановку сенсора в живом режиме (копировать вид в
   профиль, глядя на себя с фронта, заметно труднее)
2. Переключение на ближайший ракурс при облёте камерой в реплее
3. **Материал для переreconstruct** собственным детектором (см.
   `90-decisions.md`)

## FineDance — дополнительный

14,6 часа, 22 жанра, 27 танцоров, оптический mocap Vicon, 30 fps, средняя
длина 152 с (против 13 с у AIST++). Точность измеренная, а не
реконструированная. 7,7 часа на Google Drive в формате SMPLH, с wav и фичами
librosa.

**Видео нет** — поэтому дополнительный, для случаев, где видео не нужно.

## NTU RGB+D — не используем

Снят тремя Kinect v2, 25 суставов — нативная топология, была бы полезна для
модели шума. Но: доступ только для исследователей из учреждений, и **создание
производного датасета прямо запрещено** — а модель шума это оно и есть.

Не потеря: модель шума строится по собственным записям, и это даже лучше —
описывает конкретный экземпляр сенсора.

## Лицензии и репозиторий

| Источник | Условия |
|---|---|
| **AIST++ аннотации** | CC BY 4.0 (Google) — **можно распространять с атрибуцией** |
| **AIST Dance DB (видео, музыка)** | только академические исследования, нужна форма-заявка, перераспространение запрещено |
| **FineDance** | некоммерческие исследования/образование/художественные проекты, распространять нельзя, одна архивная копия |
| **NTU RGB+D** | только учреждения, производные датасеты запрещены |
| **SMPL** | бесплатно для некоммерческих исследований, регистрация |

**Правило репозитория: только код.** Скрипт скачивания вместо данных, скрипт
извлечения вместо шаблонов, никакого аудио и видео. Единственное, что можно
приложить готовым — motion из AIST++ с атрибуцией.

В README — табличка: датасет, формат, какой лоадер его читает, под какой
лицензией выдаётся, ссылка. Условия каждый принимает сам у источника.

**Поставить репозиторию явную лицензию** (MIT или Apache 2.0). Без файла
лицензии «пользуйтесь если интересно» юридически не значит ничего: по умолчанию
все права сохранены, и формально никто не вправе использовать код.
